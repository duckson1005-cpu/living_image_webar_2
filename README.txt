살아있는 그림 — 이미지 인식 WebAR

1. 압축을 해제합니다.
2. index.html, Img.png, video.mp4를 같은 폴더에 둔 채 HTTPS 정적 호스팅에 업로드합니다.
3. 휴대폰 Chrome 또는 Safari에서 배포된 HTTPS 주소를 엽니다.
4. Img.png를 다른 화면에 띄우거나 인쇄한 뒤 '카메라로 시작하기'를 누르고 카메라 권한을 허용합니다.
5. 그림 전체를 비추면 해당 면에 10초 영상이 반복 재생됩니다. 그림을 놓치면 멈추고, 다시 인식하면 이어서 재생합니다.

첫 실행은 이미지 특징 분석 때문에 시간이 걸릴 수 있습니다. 결과는 브라우저 캐시에 저장되며, 저장이 제한된 브라우저에서는 다음 실행 시 다시 분석합니다. 별도의 targets.mind 수동 제작은 필요 없습니다.

소리 켜기: 기본 무음에서 소리를 켭니다.
처음부터: 영상을 처음부터 재생합니다.
종료: 카메라 사용을 종료합니다.
영상 미리보기: 카메라 없이 제공된 영상을 확인합니다.

HTML 파일을 더블클릭하거나 휴대폰 파일 앱에서 여는 방식은 지원하지 않습니다. 카메라에는 HTTPS 환경이 필요합니다. PC 개발 환경에서는 localhost를 사용할 수 있습니다. AR 엔진을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

이미지 인식으로 제공된 영상을 겹쳐 보여주는 WebAR 방식입니다. 새로운 AI 영상을 생성하거나 캐릭터를 별도 3D 모델로 만드는 기능은 아닙니다. 영상은 기준 이미지의 700:387 비율로 면에 맞춥니다. 원본 영상과 그림 사이의 구도 차이는 원본 미디어에 따라 남을 수 있습니다.

검증: 영상 H.264/AAC, 1280×720, 약 10초 확인. 이미지 700×387 확인. JavaScript 구문 검사 완료. 실행 환경의 브라우저 제한으로 실제 카메라 인식 및 모바일 호환성은 확인하지 못했습니다.

변경: 누락된 posterA.mp4/modelA.glb 참조 제거, Img.png 기반 자동 타깃 생성, video.mp4 연결, MindAR와 호환되는 Three.js 0.151.3 사용.
